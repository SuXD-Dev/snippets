# Code Snippets

Reusable code snippets and patterns in various languages.

## Languages

| Language | File | Contents |
|----------|------|----------|
| Python | [python/snippets.py](python/snippets.py) | File ops, strings, dates, decorators |
| JavaScript | [javascript/snippets.js](javascript/snippets.js) | Arrays, objects, async, DOM utils |
| Rust | [rust/snippets.rs](rust/snippets.rs) | File I/O, word count, dedup, timer |
| SQL | [sql/snippets.sql](sql/snippets.sql) | Upsert, pagination, JSON, CTEs |
| Bash | [bash/snippets.sh](bash/snippets.sh) | Strings, arrays, files, processes |
| Docker | [docker/snippets.md](docker/snippets.md) | Cleanup, debugging, networking |

## Usage

Copy and paste as needed. Each snippet file is self-contained.

```bash
# Python
python python/snippets.py

# JavaScript
node javascript/snippets.js

# Rust
rustc rust/snippets.rs -o snippets && ./snippets
```
